# Game Design

Core loop: explore -> fight -> loot -> improve equipment -> develop Bastion -> unlock realms -> defeat bosses -> clan/events -> repeat.

Launch classes: Warrior, Mage, Archer, Assassin. Nine realms progress from Ashen Frontier to Realm of Chaos. Initial content minimums enforced by CI: 50+ enemies, 12 bosses, 32 class skills, 50 quests, 50 recipes and 100 achievements.

Combat is turn-based and visual. API owns accuracy, evasion, crits, blocks, MP, cooldowns, enemy AI and rewards. Bastion has 14 interactive buildings with bounded production and server timers. Clans support base buildings, treasury, contributions and cooperative raids; wars are feature-flagged for preseason.

First-ten-minute design target: character, first fight, first gear, level-up, Bastion, crafting, boss, meaningful reward, social function, next-realm goal.
